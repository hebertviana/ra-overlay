Overlay de conquistas

As mudanças valem na hora. A janela do overlay fica sempre visível por cima do PCSX2.

Conta

Pegue a chave em retroachievements.org → Settings → Keys. Ela fica salva em texto puro no seu perfil de usuário, então não compartilhe o arquivo de configuração.

Jogo
O que mostrar

Preenchendo os IDs, os filtros acima são ignorados e só essas conquistas aparecem, na ordem digitada. O ID está na URL da conquista no site.

Backup do memory card

Depois de detectar a conquista, o app espera o memory card ser regravado antes de compactar — útil quando o PCSX2 pede confirmação pra salvar. Se o tempo esgotar, o backup sai do jeito que o cartão estiver.

Os arquivos vão para <pasta>/backups/<ID do jogo>/, nomeados como 2026-09-10_21-45-03_ach79434_Nome-da-Conquista.zip. Dentro de cada zip vão os dois cartões e um backup.txt com a conquista, o jogo e a data. Atalho: Ctrl+Alt+B.

Aparência

Para reposicionar: Ctrl+Alt+O destrava o overlay e você arrasta com o mouse. O mesmo atalho trava de novo e o clique volta a atravessar a janela. Ctrl+Alt+R força uma atualização.
